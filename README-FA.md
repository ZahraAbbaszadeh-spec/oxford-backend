# «واژگان آکسفورد سه‌جلدی» — نسخهٔ تخت (آمادهٔ آپلود)

این پوشه فقط **۵ فایل** دارد و همه باید در **ریشهٔ (root) ریپوی گیت‌هاب** باشند،
بدون هیچ زیرپوشه‌ای:

| فایل | نقش |
|---|---|
| `server.js` | کل سرور در یک فایل (API + رلهٔ صدای زندهٔ Gemini Live) |
| `package.json` | مشخصات پروژه و دستور اجرا |
| `seed.json` | دادهٔ درس‌ها و واژه‌های هر سه جلد کتاب (۳۰۰ درس، ۷٬۷۴۱ واژه) |
| `index.html` | **رابط کامل اپ** (مسیر یادگیری، درس و تمرین، مرور لایتنر، چت و مکالمهٔ زنده با موسم) |
| `README-FA.md` | همین راهنما |

صفحهٔ قدیمی «وضعیت سرور» حذف نشده؛ به آدرس **`/status`** منتقل شده
(مثلاً `https://oxford-vocab-backend.onrender.com/status`).

## آپلود با گوشی (به‌روزرسانی)

در این به‌روزرسانی فقط **۳ فایل** عوض شده‌اند: `seed.json` و `server.js` و
`index.html` (و همین راهنما). کافی است همین‌ها را آپلود کنی:

۱. فایل‌های عوض‌شده را در همان ریپوی قبلی آپلود کن و جایگزین فایل‌های قبلی
   کن (با **Add file → Upload files**؛ مهم این است که همه در ریشه باشند).
۲. کامیت کن؛ Render خودش به‌صورت خودکار نسخهٔ تازه را مستقر می‌کند.
۳. بعد از چند دقیقه آدرس سرویس را باز کن؛ این بار باید هر سه سطح اپ باز شود.

نگران دیتابیس قبلی نباش: سرور موقع بالا آمدن فقط درس‌ها و واژه‌های تازه را
به دیتابیس موجود **اضافه** می‌کند؛ زبان‌آموزها، پیشرفتشان و معنی‌های ذخیره‌شده
پاک نمی‌شوند.

## ساخت سرویس در Render (مثل قبل)

- **New → Web Service** و ریپو را وصل کن.
- **Runtime:** Node
- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **متغیرهای محیطی (Environment Variables):**
  - `GEMINI_API_KEY` — **اجباری** برای قابلیت‌های هوش مصنوعی (معنی واژه،
    چت معلم، مکالمهٔ زنده). کلید را از Google AI Studio بگیر و فقط همین‌جا
    وارد کن؛ هرگز داخل فایل‌ها، ریپو یا اپ ننویس.
  - `GEMINI_TEXT_MODEL` — اختیاری، پیش‌فرض `gemini-3.5-flash`
  - `GEMINI_LIVE_MODEL` — اختیاری، پیش‌فرض `gemini-2.5-flash-native-audio-latest`
  - `DB_PATH` — اختیاری، پیش‌فرض `./data.db` کنار سرور
  - `PORT` — رندر خودش تنظیم می‌کند، دست نزن.

## نکته‌ها

- **هر سه سطح کامل‌اند:** سطح ۱ (ابتدایی) هم با واژه‌های خود کتاب اضافه شد؛
  حالا اپ ۳۰۰ درس و ۷٬۷۴۱ واژه دارد و هر سه سطح قابل بازی‌اند. فقط چند درس
  سطح ۱ کم‌واژه‌اند (مثلاً درس ۴۲ فقط ۱ واژه و درس ۴۳ فقط ۲ واژه) چون در
  فهرست واژه‌های خود کتاب برایشان همین‌قدر خوانا بود؛ هیچ واژه‌ای جعل نشده
  و همان چند واژه هم کامل آموزش و تمرین داده می‌شوند.
- تلفظ آمریکایی و بریتانیایی هر واژه (IPA + پخش صدا) از API رایگان
  dictionaryapi.dev گرفته می‌شود؛ اگر آن سرویس در دسترس نباشد، واژه بدون
  بخش تلفظ نمایش داده می‌شود و بقیهٔ اپ سالم می‌ماند.
- نکتهٔ پلن رایگان: دیسک رندر موقتی است و با هر استقرار دوباره، فایل
  دیتابیس (`data.db`) از نو ساخته می‌شود — یعنی پیشرفت زبان‌آموزها ریست
  می‌شود. برای تست عمومی اول اشکالی ندارد؛ برای استفادهٔ واقعی باید دیسک
  پایدار وصل شود.
- قدم بعدی بعد از این استقرار: ساخت APK پوسته با همین آدرس و بستهٔ آمادهٔ
  کافه‌بازار. **هیچ چیزی بدون تأیید نهایی زهرا در بازار ثبت نمی‌شود.**
