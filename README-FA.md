# بک‌اند «واژگان آکسفورد سه‌جلدی» — نسخهٔ تخت (آمادهٔ آپلود)

این پوشه فقط **۵ فایل** دارد و همه باید در **ریشهٔ (root) ریپوی گیت‌هاب** باشند،
بدون هیچ زیرپوشه‌ای:

| فایل | نقش |
|---|---|
| `server.js` | کل سرور در یک فایل (API + صفحهٔ وضعیت + رلهٔ صدای زنده) |
| `package.json` | مشخصات پروژه و دستور اجرا |
| `seed.json` | دادهٔ درس‌ها و واژه‌های کتاب (سطح ۲ و ۳) |
| `index.html` | صفحهٔ وضعیت سرور (فقط برای تست زنده‌بودن) |
| `README-FA.md` | همین راهنما |

## آپلود با گوشی

۱. در گیت‌هاب یک ریپوی تازه بساز.
۲. با دکمهٔ **Add file → Upload files** هر ۵ فایل را انتخاب و آپلود کن
   (هر فایل جدا هم می‌شود؛ مهم این است که همه در ریشه باشند، نه داخل پوشه).
۳. کامیت کن.

## ساخت سرویس در Render

- **New → Web Service** و ریپو را وصل کن.
- **Runtime:** Node
- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **متغیرهای محیطی (Environment Variables):**
  - `GEMINI_API_KEY` — **اجباری** برای قابلیت‌های هوش مصنوعی (معنی واژه،
    چت معلم، مکالمهٔ زنده). کلید را از Google AI Studio بگیر و فقط همین‌جا
    وارد کن؛ هرگز داخل فایل‌ها، ریپو یا اپ ننویس.
  - `GEMINI_TEXT_MODEL` — اختیاری، پیش‌فرض `gemini-3.5-flash`
  - `GEMINI_LIVE_MODEL` — اختیاری، پیش‌فرض `gemini-2.5-flash-native-audio-latest`
  - `DB_PATH` — اختیاری، پیش‌فرض `./data.db` کنار سرور
  - `PORT` — رندر خودش تنظیم می‌کند، دست نزن.

## بعد از استقرار

- آدرس عمومی سرویس (مثل `https://oxford-vocab-backend.onrender.com`) را باز
  کن؛ صفحهٔ وضعیت باید «زنده ✓» و تعداد درس‌ها و واژه‌ها را نشان دهد.
- نکتهٔ پلن رایگان: دیسک رندر موقتی است و با هر استقرار دوباره، فایل
  دیتابیس (`data.db`) از نو ساخته می‌شود — یعنی پیشرفت زبان‌آموزها ریست
  می‌شود. برای تست عمومی اول اشکالی ندارد؛ برای استفادهٔ واقعی باید دیسک
  پایدار وصل شود.
- قدم بعدی بعد از این استقرار: ساخت APK پوسته با همین آدرس و بستهٔ آمادهٔ
  کافه‌بازار. **هیچ چیزی بدون تأیید نهایی زهرا در بازار ثبت نمی‌شود.**
